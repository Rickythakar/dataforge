# DataForge

DataForge is a local-first CSV preparation workspace for operations teams. It profiles uploaded data, highlights validation issues, supports column mapping and safe repairs, previews every change, and exports a system-ready file.

## Product principles

- Data stays in the browser.
- Every repair is visible before export.
- Validation messages explain how to fix the problem.
- The demo uses synthetic data only.

## Development

```bash
npm install
npm test
npm run dev
```
